# QA Test Case Writer (qa-testcase-writer-team)

회사 표준 16컬럼 CSV 테스트 케이스를 자동 생성하는 Claude Skill입니다. 요구사항 문서(Figma / Jira / PPT / PDF / 스크린샷 / CSV 등)를 입력하면, 예외케이스 분석 휴리스틱을 적용해 Happy Path + Edge Case를 망라한 TC를 도출합니다.

> **운용 철학**: 이 스킬은 **QA 엔지니어가 잡는 케이스의 80%+ 를 자동 도출**하고, **사람이 퇴고로 마무리**하는 것을 전제로 합니다. 100% 완벽한 자동화가 아니라, QA 엔지니어의 초안 작성 시간을 대폭 줄이는 보조 도구입니다.

---

## 무엇을 하나

- **입력**: Figma, Axure, Jira, Confluence, PPT, PDF, 스크린샷, 웹 URL, CSV, XLSX 등 요구사항 문서
- **출력**:
  - `[기능명]_TC.csv` — 회사 표준 16컬럼 테스트 케이스 (불명확 요구사항은 `QA 리뷰` 컬럼에 행별 기재)
  - `[기능명]_리스크분석.md` — 위험 항목 / 발생 가능성 / 영향도 / 완화 전략
  - `[기능명]_체크리스트.md` — 커버리지 검증 + 자체 진단 메타 통계 + 사람 퇴고 권장 사항

---

## 파일 구조

| 파일 | 역할 |
|------|------|
| `SKILL.md` | 메인 — 절대 금지 사항, 핵심 원칙, CSV 형식, 작업 프로세스, 최종 체크리스트 |
| `HEURISTICS.md` | 예외케이스 분석 휴리스틱 7종 + 가벼운 UI 체크리스트 12항목 + 대규모 명세 분량 처리 전략 + 자기 진단표·자체 보강 카탈로그·재진단표 |
| `WRITING_RULES.md` | 회사 표준 16컬럼 각각의 작성 규칙 + 예상결과·QA 리뷰 작성 디테일 |
| `EXAMPLES.md` | 회사 표준 CSV 작성 예시 4종 |
| `FIGMA_ANALYSIS.md` | (Figma 입력 전용) 화면 이미지를 분석해 "화면 분석 근거표"를 만드는 전처리 단계 |

> 서브 파일들은 SKILL.md가 작업 중 `view`로 호출합니다. 단독으로 쓰지 말고 5개 파일을 한 폴더에 함께 두세요.

## 핵심 기능

### 예외케이스 분석 휴리스틱 7종
명세를 보고 누락되기 쉬운 케이스를 체계적으로 도출합니다:
1. 상태 매트릭스 케이스화 (변수 2개+ 곱집합)
2. UI 동작 + 외부 시스템 검증 페어
3. 동일 UI 결과의 사유별 분리
4. 경계값 양 끝 페어
5. 다중 시스템 동기화 불일치
6. 폼 필드별 데이터 매핑 검증
7. 모달/테이블 공간 분해

### 자체 검수 + 자체 보강
TC 1차 작성 후 스스로 진단(휴리스틱 적용률 / 시리즈 적용률 / 영역별 도출 통계)하고, 얕은 누락은 자동 보강합니다. 보강 못 하는 영역(영역 통째 누락, 명세 모순 등)은 사람 퇴고 권장 사항으로 분리해 알려줍니다.

### 하이브리드 출력
- 메타 통계 → 체크리스트.md
- 영역 누락 의심 / 휴리스틱 미적용 사유 / 명세 모순 → CSV의 `QA 리뷰` 컬럼
- → CSV만 보고 퇴고하는 QA 엔지니어도 핵심 정보를 놓치지 않습니다.

## 설치 / 사용

### Claude 프로젝트에 적용
1. 이 레포의 5개 `.md` 파일을 Claude 프로젝트 지식(Project Knowledge)에 업로드
2. 또는 Skill 디렉토리에 `qa-testcase-writer-team/` 폴더째로 배치

### 사용 예
```
"이 Figma 화면으로 테스트 케이스 만들어줘: [Figma URL]"
"첨부한 명세서로 TC 생성해줘"
"이 PRD로 QA 테스트 설계해줘"
```

### 결과물 확인 포인트
- `_TC.csv` — 실제 테스트 케이스 (스프레드시트로 열 때 **복붙 말고 import/open** 권장)
- `_체크리스트.md` — 어디가 약한지, 사람이 뭘 더 봐야 하는지
- CSV의 `QA 리뷰` 컬럼 — 🔴 높음 / 🟠 중간 / 🟡 낮음 우선순위로 확인 필요 사항 표기

## 주의 사항

- **CSV를 스프레드시트로 옮길 때 셀 복붙은 피하세요.** 셀 안 줄바꿈이 있는 CSV는 복붙 시 일부 앱이 공백을 추가합니다. `파일 > 가져오기/열기`로 여세요.
- **TC 파일은 항상 `.csv`** 입니다. (markdown 표나 `.md`가 아님)
- **불명확 요구사항은 별도 질문 파일이 아니라 CSV의 `QA 리뷰` 컬럼**에 기재됩니다.
